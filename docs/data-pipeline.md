# Data and reproduction

Run commands from the root after `python -m pip install -e .`.

1. Inspect `scripts/gpw_benchmark_scraper.py` and ingest scripts to obtain the historical portfolios. Downloaded PDFs belong locally in data/pdfs/; supply the exact revision inputs described in the scripts.
2. Historical portfolio tables and reserves are expected at output/wig_history/index_portfolios.parquet and reserve_lists.parquet; the ticker map is expected at output/maps/ticker_isin_stooq_map.csv.
3. OHLCV revision tables follow output/YYYY_MM_revision/wigYYYY_MM_ohlcv.parquet. Prepare the appropriate revision before calling `python -m mwig_replication.replicate_revision --help` or the prediction module.
4. EDA and as-of backtest scripts consume earlier outputs. Reality-check inputs are listed at the top of scripts/signal_reality_check.py; set MWIG_BENCH_DIR to the directory containing benchmark TXT files, or put them under data/raw/benchmarks/.

`output/` remains the operational generated-artifact path to preserve the research pipeline. `results/` documents reference/output policy; no duplicate copies of large outputs are added. Existing data snapshots and manual corrections remain under data/ with their original names. Missing artefacts are not invented or regenerated by this migration. This is a dependency map, not a claim that the entire pipeline is reproducible without external data.
